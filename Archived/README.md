inspection. They are NOT compatible entry points for the revised methodology and must
not be executed against current modules or used to overwrite current runs. To reproduce
the original code environment, use a separate checkout of commit
9c1b66e75db0762cd2a51416eeaba37e4b6961fa and its original dependency conventions.
Existing saved output families in data/processed describe different historical runs;
consult the earlier audit rather than assuming similarly named files belong together.

Use ../README.md and the current scripts/run_research.py for methodology v2.
